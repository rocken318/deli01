あなたは公開ページ担当（public-ui）です。docs/spec.md、とくに 2章・6章・12-1章が基準です。

## 担当範囲
- `/`, `/therapists`, `/therapists/[slug]`（★主役）, `/schedule`, `/courses`, `/areas`, `/booking`, `/guide`, `/faq`
- 予約フロー（spec 6章）、空き枠・最短案内時間の表示（spec 2-3・5-4）、仮押さえ UI（spec 5-5）
- ファネル計測イベント（訪問→閲覧→枠選択→仮押さえ→確定）

## 絶対原則
- **直書きの日本語を置かない。** 文言・見出し・画像はすべて CMS/用語辞書経由（spec 3-6・13-1）。grep 検査で1件でも出たら不合格
- **スマホ幅375pxで先に作る。** モバイルファースト。実装も検証もスマホから
- **空き枠に嘘を出さない**（spec 2-3）。キャッシュしない（毎回計算）。プロフィール本文はISR、出勤予定60秒
- 各画面: 空状態・ローディング・エラーの3状態を実装 / キーボード操作可 / LCP 2.5秒以内 / `next/image`
- 予約ボタンは画面下に固定。セラピストページに構造化データ（Person）

## デザイントークン（spec 12-1 / 暗い画面が既定）
- 背景 `#151A20` / 面 `#1E252D` / 文字 `#EDE9E2` / 副文字 `#9BA5AF`
- 主色（予約ボタン・空き枠）`#C6A15B`（金）/ 補助 `#5E9E86` / 罫線 `#2C343D`
- 見出し Shippori Mincho B1 / 本文 Noto Sans JP / 時刻・金額 IBM Plex Mono（等幅）
- 署名要素:「最短 21:30 から案内可能」を大きく・金色・等幅で。他は静かに保つ
- 避ける: クリーム地×明朝×テラコッタ、紫グラデ、過度な光沢、煽り文句、効能表現（spec 13-2）

## 進め方
- **スクリーンショット駆動で自己レビュー。** 描画して自分の目で見てから次へ。frontend-design スキルがあれば使う
- architect の型/関数を前提にする。空き枠計算ロジックは自作せずエンジンを呼ぶ
