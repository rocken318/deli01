# CMS 変更手順（非エンジニア向け）— cms.md

コードを触らずに、サイトの項目・文言・画像・料金などを変える手順（spec 3章・13章 / L1163）。**このサイトは多くを「コードでなくデータ」で持つ**ので、管理画面から変えられる。

## 変えられるもの と 画面

| 変えたいもの | 画面 |
|---|---|
| セラピスト等の**入力項目**を増やす／ラベルを変える | `/admin/fields`（フィールド定義） |
| セラピスト・各レコードの**内容** | `/admin/records` → 対象を開く |
| トップや固定ページの**見出し・文章・画像** | `/admin/pages` → 対象ページ |
| 屋号・電話・営業時間・SNS・**料金設定・キャンセル/ポイント/直前割の設定** | `/admin/settings`（サイト設定） |
| 画像（alt・タグ・掲載同意） | `/admin/media` |
| コース・オプション・ホテル・エリア・レート | 各管理画面 |

## 下書き → 公開（重要）

- 変更はまず **下書き（draft）** に入る。**公開ボタンを押すのは人間だけ**。プレビューで確認してから公開する。
- **画像は alt（代替テキスト）が無いと公開できない**。人物写真は**掲載同意**が無いと公開されない。退職処理をするとそのセラピストの画像・公開プロフィールが一括で非公開になる。

## 用語辞書と禁止語

- **サイト全体の呼称は用語辞書（サイト設定）で一括変更**できる。公開ページは直書きせず用語辞書を参照している。
- **公開時に禁止語リストと照合して警告**が出る（ブロックはせず警告。運営が判断して公開）。リストは CMS から編集可能。**サイト文言にもかかる**（セラピストのプロフィールだけでない）。

## AI アシスタント（任意）

`/admin/ai`: 文章の**下書き生成・リライト・トーン調整・禁止語の言い換え提案・表記ゆれ統一**を Claude に頼める。
- **AI の出力は必ず下書き止まり。AI は公開できない**（承認するのは人間）。
- 構造の変更提案も**差分プレビュー → 人間が承認**を挟む。AI が直接実行しない。
- すべての依頼・出力・承認/却下は履歴（`ai_actions`）に残る。詳細は [ai-assistant.md](./ai-assistant.md)。

## お知らせ・バナー

掲載期間を設定でき、期間が過ぎると自動で消える。ブロックの並べ替えで表示順が保たれる。
